DeepSeek Harness 与 dsh

夜间巡航（Night Cruising）是基于 DeepSeek Harness（deepseek-harness） 独立维护的桌面发行版，提供夜间主题工作区和长任务持续等待功能。本网站提供夜间巡航版的下载、版本记录与安装说明。

DeepSeek Harness 桌面版
通过图形界面使用 AI 工作区。夜间巡航在 DeepSeek Harness 基础上提供深色主题，并支持用户随时主动取消模型请求。
dsh 命令行工具
dsh 是 DeepSeek Harness 的命令行入口。夜间巡航安装包附带该工具，便于在终端中使用；Linux 包内入口为 resources/runtime/cli/bin/dsh。
Windows、macOS 与 Linux 下载
提供 Windows EXE、macOS DMG，以及 Linux x64 的 tar.gz、DEB、AppImage。前往 DeepSeek Harness 夜间巡航版下载页 查看安装包、历史版本与文件校验值。

版本特性

长任务持续等待
模型请求和流式响应取消了应用层超时。即使模型长时间没有返回新内容，仍会继续等待，你可以随时手动取消。
夜间巡航工作区
工作区默认采用深色配色，底部是一幅骑手穿过跨江大桥的夜景。点「播放音乐」即可循环播放随包的合成器配乐，再点一次暂停。
Linux 桌面版
提供 Linux x64 的 tar.gz、DEB 和 AppImage 下载。DEB 可用于 Debian、Ubuntu 等发行版，AppImage 赋予可执行权限后即可运行，也可以使用随包的 dsh 命令行工具。
