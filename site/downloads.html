安装 DeepSeek Harness 夜间巡航版

夜间巡航是基于 deepseek-harness 独立维护的桌面发行版。安装包附带 dsh 命令行工具，可同时使用桌面工作区与终端入口。

Windows 与 macOS
Windows 运行 EXE 安装器；macOS 打开 DMG，将应用拖入 Applications。
Linux x64
DEB 适用于 Debian、Ubuntu 等发行版；AppImage 赋予可执行权限后运行；tar.gz 解压后运行 ./night-cruising。Linux 包内的 dsh 位于 resources/runtime/cli/bin/dsh。
版本与文件校验
展开安装包下方的说明查看 SHA-256 校验值和校验文件。也可前往 夜间巡航 GitHub Releases 查看发行包，或阅读 DeepSeek Harness 与 dsh 介绍。
