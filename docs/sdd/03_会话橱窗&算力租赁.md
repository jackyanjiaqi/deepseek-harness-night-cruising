# 会话橱窗&算力租赁

## 深夜巡航匿名登陆体系

只需要上传一个名字和头像就可以作为橱窗发帖和浏览板留言的发言人。

注意，匿名登陆体系始终以 dsh 的指纹，指纹包括你用 dsh 跑本地大模型的使用数据来识别你，而非匿名名字和头像。使用会话橱窗能够强化你发布过的会话，你将成为平台上独一无二的你。这里的你不仅仅指自然人的你，还包括你机器的算力和dsh背后的大模型，可以说你即是 agent，agent 即是你。

## 会话橱窗

类似一种测评机制，你可以发布一个作品，比如网页(上传时是一个zip包)然后可以打开游玩，然后你必须附上这条会话 id 和 它所对应的 session 日志。这种机制类似 omlx 的性能测试(benchmark)可以让人迅速看到在同一个平台上的大模型和agent能力差距，以及如何设置来加载到相似水平。

注意当别人发现你的会话经常提到一些现成的工程时，你的参考工程在某些人看来就有大用途，我们未来设计了拍卖，一口价等机制让你售卖自己的工程资源，包括完整的提示词，产物以及参考素材甚至是dsh特殊配置。dsh 会根据不同人的使用逐渐变得千人千面。快速从他人的会话成果获得参考工程具有巨大价值，同时售卖的人可以获得一点回血。

## 算力租赁

当深夜来临，我们的深夜巡航版本会在夜晚一直运行任务，当有任务提前运行且模型处于挂载空置状态，你可以设置用来跑他人的子任务来赚一点外块，算力租赁同样以 token 计费，并形成社区贡献。
