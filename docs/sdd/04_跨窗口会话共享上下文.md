# 跨窗口会话共享上下文

充分阅读源代码 搞清楚dsh web 部署和 desktop 部署到底有多大区别:

- 直接用 web 启动，让 desktop 提供一层轻量的 chromium 外壳，通过加载 远程 web 页面达到操作远程 session 的目的。

- 还用 desktop 启动本地 session 但是套一层 rrweb 进行界面录制，对 dsh 的虚拟列表进行优化，将录制数据流远程传输给其他 desktop 播放端，同时设置输入框可以打字点击发送，到远端监看的那个会话内。注意该方式类似远程访问，但是被监视的一端发送数据流并接收打断输入，监视的一端播放数据流并可以输入文字打断远程 session。

- 注意算力租赁需要保护好自己的 session 数据，与共享上下文正好相反，后者是自己配置的多个端，方便在不同机器上共享会话，无缝衔接工作。
