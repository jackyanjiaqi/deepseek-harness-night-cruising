# P2P实时电台

## 主播搭建实时电台

主播身份可以利用自己的电脑充当临时服务器，将目标 dsh 连接到自己的主机，搭建临时聊天窗，采用 websocket 语音通信

- 需要目标机器呼入，类似电话接听机制，接听后形成一个公开频道，一个频道固定只有主机一个麦克风，以及一个坐客麦克风，具体有几个麦克风由主机性能和网络以及主机开房间的预设决定。

- 主播开播前需要进行预告，预告消息放在深夜巡航底部滚动栏，听众可以提前进行预约，预约需要上报手机号，预约信息将提交给主播，由主播决定如何通知听众。

- 电台开播后，只要有人在频道中，其他人可以静音加入收听(听众)，形成实时电台。

- 静音加入的人可以抢麦克风，但是抢到麦克风的人需要根据当前房间抢麦克风的人数进行读秒发言。

- 同时有聊天板，所有人匿名可以在聊天板上留言。

- 语音聊天也会接入 asr 进行语音转文字 存入电台知识库。

- 后期 AGENT 接入 tts 文字转语音 mcp 后可读取电台知识库，充当 24小时值守电台主持。

## 反馈入口增加实时电台

使用软件有问题的人可以点击实时电台，打开正在进行播放的实时电台，以及播放预告。
同时他可以看到过去刚刚直播完电台的聊天板，以及当天最热话题。

注意，电台主播下播前有义务利用自己的算力上报，上报主要以 oss 事件流的形态上报，本次直播的文字记录和最热话题，

## 主播可以播放自己本地音乐作为电台歌单

故名思义，由主播通过自己的广播链路向自己房间内的静默听众播放自己本地音乐，此时主播类似电台 DJ, DJ 模式下，主播可以自己发言，发言时音乐声音自动变小，但是必须保持始终有音乐在播放。
