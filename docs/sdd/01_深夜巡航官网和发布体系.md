# 深夜巡航官网和发布体系

## 网站体系

利用七牛的静态站点功能，将网站组织成静态网站放在 site 目录下，站点页面尾部都要放网站的 备案号 在 env.local 下 ICP

需要提供原始 git 链接和下载地址，下载地址请看发布体系

## 发布体系

使用 .env.local 内的字段值参考 cmd_tools/uploadToQiniu.js 进行产物上传，脚本计算最新版本并下载覆盖上传 特定文件。

采用静态文件能够列出所有已发布版本，并列出最新版本放在 网站下载页面，能够区分 linux windows mac 不同平台，当只发布了一个平台时网页只显示一种平台的入口。

静态网站只根据静态json文件接口渲染画面，并提供下载链接。

网站自身也有发布体系，大版本跟随 package.json version 字段，附带-小版本号暂时用日期格式 YYYYMMdd-v数字 当同一天多次发版时 数字递增

网站版本显示在。

提供网站部署脚本，将 site 目录内容全部按照静态文件上传到目标 bucket 完成静态网站部署。

域名在阿里云注册 partyplay.top 已备案，需要七牛云配置子域名 deepseek-harness-night-cruising，并设置阿里云 90天手动更新的免费 ssl 证书，网站本地测试通过后 给我一份七牛静态站点部署手册方便我进行实施
