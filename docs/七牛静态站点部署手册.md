# 深夜巡航官网部署手册

目标地址为 `https://deepseek-harness-night-cruising.partyplay.top/`。官网使用七牛 Kodo 静态托管，浏览器只读取同域的 HTML、图片、脚本和 `data/releases.json`。首页和下载页的页脚显示网站版本与工信部备案链接。导航里的「上游源码」指向 DeepSeek Harness 原始项目。

## 1. 在本机验收

在巡航工程根目录使用 Node.js 24 执行下列命令。全新克隆可从 `.env.local.example` 创建 `.env.local`，填写实际备案号 `ICP`。已有配置直接沿用。本地预览只需要备案号。

```sh
npm ci
npm run site:test
npm run site:plan
npm run site:preview
```

浏览器打开终端打印的地址，默认是 `http://127.0.0.1:4173/`。进入「下载」，核对版本、平台、架构、文件大小及 SHA-256。点击校验值可展开并下载校验文件。预览服务器直接从 `dist/` 提供下载，站点目录无需保存第二份安装包。端口被占用时可运行 `PORT=4174 npm run site:preview`。

## 2. 配置七牛空间和域名

1. 在七牛对象存储新建或选用巡航站点**专用的公开读空间**，记下空间名和存储区域。网站会写入空间根目录的 `index.html` 等固定对象，其他站点继续使用各自的空间。
2. 在该空间的静态页面管理中开启「默认首页」，首页文件为根目录的 `index.html`。下载页使用显式路径 `/downloads.html`。本手册采用 Kodo 自定义源站域名直连，无需单独创建 CDN 加速域名。[七牛静态页面管理](https://developer.qiniu.com/kodo/8604/a-static-page-management)
3. 打开空间的「域名管理」，添加自定义源站域名 `deepseek-harness-night-cruising.partyplay.top`，按控制台要求完成域名归属校验。记录七牛为此域名给出的 **CNAME 目标值**。[七牛绑定源站域名](https://developer.qiniu.com/kodo/8556/set-the-custom-source-domain-name)
4. 在 `partyplay.top` 的权威 DNS 控制台添加 CNAME。使用阿里云 DNS 时，进入云解析 DNS → 域名解析 → `partyplay.top`，主机记录填 `deepseek-harness-night-cruising`，记录值粘贴七牛给出的目标值。保留主域和其他子域的现有记录。用 `dig +short CNAME deepseek-harness-night-cruising.partyplay.top` 核对返回值，再回七牛确认绑定状态。[CNAME 配置说明](https://developer.qiniu.com/fusion/4941/cname-configuration)

## 3. 申请证书并开启 HTTPS

1. 在阿里云数字证书管理服务申请 **个人测试证书（免费版）**，绑定完整子域名 `deepseek-harness-night-cruising.partyplay.top`。选择 DNS 验证。手动验证时，按证书页面给出的记录类型、主机记录和记录值另行添加验证记录。业务 CNAME 继续指向七牛。[阿里云免费证书申请与下载](https://help.aliyun.com/zh/ssl-certificate/product-overview/get-started-with-free-certificates/)
2. 签发后下载 Nginx 格式证书，在七牛 SSL 证书服务上传自有证书。证书内容填写含中间证书的 PEM 证书链，私钥填写匹配的 KEY。私钥只在证书管理控制台使用。
3. 回到七牛空间的源站域名配置，为该子域名绑定证书，开启 HTTPS。使用浏览器检查证书覆盖的域名和到期日；首次上传前，空空间返回 404 也可以完成 TLS 验证。[七牛源站域名 HTTPS](https://developer.qiniu.com/kodo/8556/set-the-custom-source-domain-name)
4. 阿里云说明个人测试证书有效期为 90 天，适合开发测试。按实际签发到期日设置日历提醒，建议提前 30 天申请下一张证书。新证书签发后，在七牛上传并切换绑定，再从公网检查新的有效期。域名解析可继续沿用。[阿里云证书有效期和适用范围](https://help.aliyun.com/zh/ssl-certificate/purchase-an-individual-test-certificate)

## 4. 填写发布配置

| .env.local 字段 | 值 |
| --- | --- |
| `BUCKET` | 上面绑定巡航子域名的专用空间名 |
| `DOMAIN` | `https://deepseek-harness-night-cruising.partyplay.top` |
| `UPLOAD_HOST` | 该空间所在区域的七牛 HTTPS 上传入口，从空间控制台核对 |
| `ACCESS_KEY`、`SECRET_KEY` | 用于查看空间绑定域名、查询对象、上传对象和删除发布锁的七牛凭证 |
| `ICP` | 该网站实际备案号，含完整序号 |

脚本先检查配置的主机名，再通过七牛管理接口核对域名与空间的绑定关系。上传凭证限定于具体对象，安装包直接从磁盘上传。浏览器获得的清单只含备案号、网站版本和下载元数据。[七牛上传策略](https://developer.qiniu.com/kodo/manual/put-policy)

## 5. 发布软件与官网

1. 从各平台原生构建机收集 `npm run release` 的产物以及同名 `.sha256`，放在发布机的 `dist/`。可用 `npm run release:source` 增加源码包。例如 macOS ARM64 的文件形如 `night-cruising-0.1.0-darwin-arm64.dmg`。Windows 识别 `win32-<架构>.exe`，Linux 识别 `linux-<架构>.tar.gz`。文件名中的版本即该软件版本。
2. 运行 `npm run site:plan`，核对本地产物和对象路径。该命令校验 SHA-256，并给出本地预览版本。正式版号由部署时的线上状态决定。
3. 运行 `npm run site:deploy`。脚本先获取空间内的发布锁，读取并核对线上清单，然后上传新产物、校验文件及 `site/` 中的公开页面与资源，最后覆盖 `data/releases.json`。安装包 URL 带版本号和内容哈希；同一版本补发 Windows 包会保留已有的 macOS 包，同平台重打包会将入口指向新内容。旧下载对象继续可用。
4. 打开线上首页和下载页，确认备案链接、网站版号、最新版本与历史版本。下载一个安装包和对应的校验文件，在同目录运行 `shasum -a 256 -c 文件名.sha256`。Windows 可用 `Get-FileHash 文件名 -Algorithm SHA256` 与页面对照。

网站版号采用 `<package.json version>-YYYYMMdd-vN`，按上海日期计算。当天第二次成功发布由 `v1` 升至 `v2`，次日从 `v1` 开始。软件下载按语义版本号排序，正式版排在同号候选版之前。只有上传过的安装包才会生成平台入口。

## 故障处理

| 现象 | 处理 |
| --- | --- |
| 提示 DOMAIN 或空间绑定错误 | 检查巡航子域名、HTTPS、空间名和域名绑定；从其他项目复制的配置需逐项核对。 |
| 校验失败或缺少 .sha256 | 从同一次构建复制安装包和校验文件，重新执行预演。 |
| 上传中断 | 重试同一命令。已上传且内容相符的安装包可复用。以线上 JSON 最后一次成功更新为准。 |
| 发布锁冲突 | 等正在运行的发布完成。若机器异常退出，在确认所有发布进程已结束后，从专用空间删除 `data/site-publish.lock` 再重试。 |
| 清单与空间不一致 | 检查源站域名是否指向本空间。若另加 CDN，将 `/data/releases.json`、HTML、JS 和 CSS 设置为不缓存或发布后刷新，再重试。带内容哈希的安装包适合长期缓存。 |
| 需恢复某平台上一份安装包 | 把旧安装包及对应校验文件放回发布机 `dist/`，再次部署即可切换该版本的平台入口。网站日期序号按一次新发布递增。 |
