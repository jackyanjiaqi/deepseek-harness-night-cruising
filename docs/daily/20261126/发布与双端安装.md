## 两端安装

1. 两台 Mac 各自解压 zip，把 `DeepSeek Harness.app` 放入 `/Applications`。
2. 在每台机器安装插件：

```sh
dsh plugin --profile desktop add /path/to/dsh-account-mesh-0.1.0-rc.13.tgz
```

3. 确认 Night Cruising 版本自动判定：GUI 启动时 Host 环境带 `DSH_DISTRIBUTION=night-cruising`，插件默认 `codec: auto` → JLC active。
4. 两端登录同一 DeepSeek 账号，局域网/Tailscale 互通；插件设置页应看到对端 verified。
5. 远端工作区选择会话 → “JLC 拉取完整会话”。首次拉取写入加密“保险柜”（`vault/*.ncv`），不写明文会话文件；关闭 DSH 后自动清除。
