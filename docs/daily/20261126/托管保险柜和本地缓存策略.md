# 托管保险柜和本地缓存策略

> 设计产出（2026-11-26）：[`plugins/account-mesh/docs/托管保险柜与本地缓存.md`](../../../plugins/account-mesh/docs/托管保险柜与本地缓存.md)。下面是原始需求笔记，保留为设计输入。

保险柜的一个重要的功能是远端机器在目标本地机器上工作空间内托管一个加密文件容器，对于拉取会话数据这种大型文件，如果下次进入界面再次拉取非常消耗时间和带宽，通过在目标本地机器上的一个工具方法让其通过远端通道获得保险柜钥匙，从而获得打开保险柜文件和组织返回值的能力，等于是将远端请求变成本地请求，注意这里依然要通过请求协议来交换数据，并不等同于本地dsh拿到了钥匙打开了本地文件。

你想想办法如何达到 远端的操作者不被对方控制从而变相解密托管文件。

这样每次打开相同的远端会话时，都可以秒开，注意可能需要一种利用通道传递交换钥匙的能力，比如上一个钥匙失效更换下一个钥匙，类似2步验证，或者信道传输短信验证码一样。跟浏览器管理cookie和一些敏感数据放在临时目录一样，不会让用户轻易拿到。
