# 细节优化

- mac 版本应用窗口模式时 左上角有三个固定的系统按钮，远端工作区标题在靠近左侧时文字应该让出按钮这部分区域，可以阅读苹果的设计规范或者参考 dsh 官方面板标题区的做法。

- 文档服务 设置界面也要加入 版本显示 参考"同账号互联"

- 远端工作区 会话列表 

    - 时间没有对齐到右侧，依然有看不见的隐藏复制按钮占位，同时没有hover悬浮显示的效果。这里与官方工作区的交互逻辑要一致，因为平时查看会话标题尽可能预留空间。只在需要交互时展示按钮。

    - 三角符号可以去掉了 图标占据左侧太多区域了，而且你使用的控件不可以用外部图标代替 自带的三角图标么 现在三角图标和电脑/文件夹图标并排 很难受 空间占用太大了

    - 优化排列顺序，离线的放在后面，有最新时间会话的终端设备排在前面，能区分 固顶会话，无标题空会话 0b 这些特征的会话暂时过滤掉不要展示，纯占地方毫无价值。全部是空会话的工作空间也不要展示，过滤掉。

- 底部栏关闭方式不要只是点按钮，而是点击外部区域就可以关闭，你试试通过修改源码实现。
