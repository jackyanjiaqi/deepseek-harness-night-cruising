# 底部栏配置扩展 · 心跳与重复守卫

- 日期：2026-11-26
- 补丁：`013-bottom-settings-heartbeat-guard.patch`（接在 012 超时统一配置之后）
- 配置说明：`bottom-settings.mjs`
- 前言：`012` 已让等待/工具超时统一读取底栏；本期补齐底栏配置项、作业状态心跳、重复守卫窗口与工作流子智能体心跳，并移除 `tool-jobs` 中可覆盖底栏的配置钉死。

## 1. 底栏新增配置

`bottom-settings.mjs` 现在是配置项的说明来源；运行时目录在
`packages/bundle/web-app/src/night-timeouts.ts`。两类单位：

- `ms`：界面按“秒”编辑，保存时转回毫秒；
- `count`：界面按“次”编辑，保存整数。

新增分组：

| 分组 | 键 | 默认 | 作用 |
| --- | --- | --- | --- |
| 运行观测 | `job.status.afterMs` | 5 分钟 | 作业运行/静默超过该阈值后，状态行附带 running / idle |
| 运行观测 | `workflow.progress.interval` | 60 秒 | workflow 子智能体刷新 job progress 的最小间隔 |
| 重复调用守卫 | `guard.repeat.enabled` | 1 | 0 关闭，1 启用 |
| 重复调用守卫 | `guard.repeat.window` | 24 | 最近 N 次跟踪调用 |
| 重复调用守卫 | `guard.repeat.windowThreshold` | 8 | 窗口内同签名 N 次提醒，后续 N×2、N×4 |
| 重复调用守卫 | `guard.repeat.every` | 20 | 超过最大阈值后每 +N 次再提醒 |
| 重复调用守卫 | `guard.repeat.block` | 0 | 0 仅提醒，1 在阻断阈值拒绝调用 |
| 重复调用守卫 | `guard.repeat.blockAfter` | 40 | 阻断阈值 |

保存后通过 `configureTimeouts`/`settingNumber` 立即发布；`job.status.afterMs` 等非超时数值也走同一存储，不再另设配置。

## 2. 只保留底栏作为唯一来源

- 删除 `tool-jobs` 的 `waitTimeoutMs` / `maxWaitTimeoutMs` 配置项。
  `job_output` 每次执行只读 `wait.job.default` / `wait.job.max`，profile 不能再钉死另一套等待。
- `wait_agent`、`session/wait-timeout`、`deadline()` 的映射路径同样只读底栏。
- `bash`、持久终端、工作树、网页抓取、LSP 仍可声明自己的请求预算，但 `deadline()` 只用底栏值做最终上限；底栏为 0 时不装表。
- 模型请求相关 capability code 不在 `DEADLINE_SETTINGS` 内，保持无应用层超时。

## 3. 作业状态心跳

| 位置 | 改动 |
| --- | --- |
| `packages/jobs/jobs/src/view.ts` | `JobView.updatedAt?` |
| `packages/jobs/jobs-local/src/index.ts` | `TrackedJob.updatedAt`；append/progress/settlement 刷新；`view()` 投影 |
| `packages/jobs/tool-jobs/src/render.ts` | `PublicJobSnapshot.updatedAt`；`statusLine()` 对 running/stopping 在超过阈值后追加 `2h00m, idle 1h00m` |
| `packages/jobs/tool-jobs/src/index.ts` | `job_output` 输出 schema 增加 `updatedAt` |

这样 17 小时的阻塞不再只显示 `(no new output)` / `[status: running]`，而是每次读取都能看到已运行与静默时长。阈值可调，测试中的快速作业仍保持原来的短状态行。

## 4. 重复守卫窗口

`packages/guard/repeat-tool-reminder/src/index.ts`：

- 保留连续阈值 `[3, 5, 8]` 的 gentle/detailed 文案；
- 新增滑动窗口（默认 24），窗口内同签名达到 `8/16/32` 时提醒，覆盖 A/B 交替；
- 超过最大阈值后按 `repeatEvery` 持续提醒，不再第 8 次后永久静默；
- 可选 `escalation: 'block'`，底栏 `guard.repeat.block=1` 且计数达到 `blockAfter` 时把该次调用变成 `isError`，同时保留提醒上下文；默认关闭。

## 5. 工作流子智能体心跳

- `workflow/types.ts` 新增 `WorkflowAgentProgressInfo`；
- `workflow/index.ts` 新增 `workflow/agent-progress` 事件；
- `workflow-ptc` 在 `agentStart` 时订阅子智能体 `agent/pre-step`，按 `workflow.progress.interval` 节流，`agentEnd`/run 结束时退订；
- `tool-workflow/record.ts` 把心跳写成 job progress `phase · step N`，不写 `log` ring，避免膨胀。
