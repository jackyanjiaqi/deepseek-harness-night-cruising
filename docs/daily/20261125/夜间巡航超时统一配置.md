# 夜间巡航底部栏 · 统一超时配置

- 日期：2026-11-25
- 输入：[会话超长异常诊断](会话超长异常诊断-session-8b340fbc.md) · [修复方案](修复方案-会话卡死与日志膨胀.md) · `session-b3565d5b` 诊断结论
- 状态：已实现（补丁 `012-night-cruising-timeouts.patch`）
- 红线：不恢复模型请求超时；到期只返回状态或结束该次操作

## 1. 为什么不能继续一刀切

`002-disable-operation-timeouts.patch` 把 `deadline()` 改成 no-op 后，DSH 内部**依赖超时事件推进**的路径一起失效：

| 消费者 | 事故表现 | 本次处理 |
| --- | --- | --- |
| `job_output(wait:true)` | `timeout_ms` 形同虚设，父会话阻塞 6h30m / 11h06m | `waitDeadline()` 真实到期，返回 `[status: running]`，不 kill |
| `wait_agent` | 自带 `setTimeout` 被固定成 24.8 天，子智能体等待永不返回 | 默认/上限改为读取底部栏设置 |
| `session/wait-timeout` | 远端会话等待无法到期 | 默认值改为读取底部栏设置 |
| 工具声明 `timeoutMs` | `core/tools` 把声明值改写成 24.8 天 | 恢复声明值，由 `TOOL_TIMEOUT` 映射决定是否执行 |
| Shell / 持久终端 / 工作树 / 网页抓取 / LSP | 统一被禁用 | 默认仍为 0（不限制），可在底部栏按项启用 |

模型请求（`LLM_STREAM_IDLE_TIMEOUT`、`MESSAGES_IDLE` 等）不在映射表内，保持仓库政策要求的无超时。

## 2. 架构

```
夜间巡航底部栏（apps/web）
  GET/PUT /night-cruising/timeouts
        │  (connection.admit 浏览器鉴权)
        ▼
packages/bundle/web-app/src/night-timeouts.ts
  · 目录 catalog（分组、标签、默认值、上下限）
  · 原子写入 $DSH_HOME/night-cruising/timeouts.json
  · configureTimeouts(values) ──► @deepseek-ai/dsh-timeout
                                      │
              deadline(code) ◄────────┤ DEADLINE_SETTINGS: code → settings key
              timeoutSetting(key) ◄────┘
        │
        ├─ jobs-local.waitJob    → waitDeadline（到期 resolve，job 继续跑）
        ├─ tool-jobs             → 每次 job_output 读取 wait.job.default / max
        ├─ tool-subagent-control → 每次 wait_agent 读取 wait.agent.default / max
        ├─ session-controller    → 每次 wait 读取 wait.session.default
        ├─ timeout-policy guard  → deadline(TOOL_TIMEOUT) 按 tool.call 生效
        └─ bash / persistent bash / worktree / web-fetch / lsp → deadline(code)
```

`configureTimeouts()` 发布过一次完整值后，**未出现在映射里的键一律不装表**；设置服务不可用时（独立页面、无鉴权），`deadline` 恢复为调用者传入的期限，保证既有单测与嵌入式使用不回归。

## 3. 底部栏交互

- 折叠：只保留原有「夜间巡航 / 播放音乐」和一行极简白色文字：`超时 30 秒 · 上限 10 分`。
- 展开：点击白色摘要，面板从底栏向上生长；`body` 是 `minmax(0,1fr) auto` 网格，**只压缩应用区域，不覆盖任何面板**。
- 预留距离：展开高度 `clamp(220px, 52vh, 540px)` 且 `max-height: calc(100dvh - 300px)`，短窗口至少给应用留约 300px；面板内部滚动。
- 大量配置：分组 + `auto-fit` 网格 + 分组标题吸顶 + 筛选框；插件新增目录项不需要改布局。
- 输出完成：保存后（以及对话 Stop 按钮消失、即一轮输出结束时）摘要保持白色极简并轻微闪一下；状态行显示「已保存，立即生效」。
- 字号/间距：11px 摘要、10–11.5px 行文本、6px 行距；与底栏 46–62px 高度、12–40px 内边距对齐。
