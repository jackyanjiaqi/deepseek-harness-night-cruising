# 托管保险柜实现与验收（2026-11-27）

> 需求：`docs/daily/20261126/托管保险柜和本地缓存策略.md`、插件内设计稿。  
> 实现版本：`dsh-account-mesh@0.1.0-rc.15`；桌面壳层补丁 `017-hosted-vault-bottom-bar.patch`。

## 1. 角色与两个设置面

| 设置面 | 用户身份 | 决定什么 |
| --- | --- | --- |
| **远端在本机的托管** | 本机是 A（观看方/存储宿主） | 远端设备的数据放在本机哪个可写目录；何时删除；是否允许新设备接入 |
| **本机托管到远端的策略** | 本机是 B（数据所有者/远端） | 钥匙多久过期、托管账本保留多久、自动/拒绝/确认放行；可撤销某台设备 |

底栏“托管保险柜”同时展示这两面，避免把“我的数据放在哪”和“别人的数据放在我哪”混在一起。

## 2. 后端

### 2.1 NCV2 容器

- A 侧每个对象一对文件：`<workspace 相对路径>/<hash>.hdr` + `.dat`；
- `.dat`：随机 `DEK` 加密 archive + gzip 投影 sidecar；
- `.hdr`：`depositId`、代次、`kind/variant`、`archiveSha`、`DEK` 的 `K_g` 包裹；
- 换钥只重写 `.hdr`；`.dat` 不变；
- 文件名/头无标题、路径、原始 session id；只有哈希、随机 id 和内容哈希；
- A 索引 `hosted-vault/index.json` 持久化哈希键、容器路径、代次、字节数；B 账本/根密钥在 B 的 `hosted-vault/ledger.json`、`root.key`。

### 2.2 协议

| 操作 | 方向 | 作用 |
| --- | --- | --- |
| `sessions/export/prepare` | A→B | 首次创建 deposit，返回 `K_0`、`depositId`、content hash、sessionCwd |
| `vault/open` | A→B | 校验 peer/deposit/gen/archiveSha/kind/variant，返回 `K_g`、`K_{g+1}`、过期时间、fresh、签名 |
| `vault/commit` | A→B | A 已把 `.hdr` 重包到下一代；B 推进 `confirmedGen` |
| `vault/revoke` | B 本地 | 撤销某设备全部托管；A 下次打开删除本地容器并回退完整 JLC |

- 票据指纹/代次/签名绑定；旧代、跳代、别的设备、别的 archive 都拒绝；
- B 不接收密文、不代解密；过期票据只拒绝本次开柜，不删容器；
- 撤销是硬状态；远端可在运行期间撤销。

### 2.3 目录与倒计时

- 每个 peer 一个可写 root；默认 `<cwd>/.night-cruising/vault/<peer>`；
- 自动目录不可写 → pending 请求，`expiresAt = now + vault.approvalTimeout`；超时自动 denied；
- 本机用户可在底栏 pending 卡片输入目录，或“打开目录”；
- `vault/host/delete` 删除某 peer 全部 `.hdr/.dat`；**删除后才允许更换目录**（后端 `vault-not-empty` 守卫）；
- `vault/host/open` 调系统文件管理器。

## 3. 底栏入口

- 与“超时”平行的 `托管保险柜` 按钮；
- 展开面板两个 scope：
  1. 远端在本机的托管：peer、路径、容器数、打开目录/更换目录（有内容时禁用）、删除内容、待确认倒计时；
  2. 本机作为远端：托管给哪些设备、撤销托管、release 策略、账本保留、钥匙 TTL（跳转/读取底栏超时设置）。
- 计时设置：
  - `vault.approvalTimeout`（默认 60s）：目录选择等待，到期自动拒绝；
  - `vault.keyTtl`（默认 600s）：开柜票据有效期；
  - 二者都在底栏“超时设置”里，不是模型请求超时。

## 5. 已知边界

- 当前 P1 票据经 DTLS + Ed25519 认证 RPC 投递；设计中的额外 X25519 链路包裹尚未实现；
- `vaultRelease: confirm` 暂返回 `confirmation-required`，本地确认 UI 未实现；`auto`/`deny` 可用；
- `.dat` 成员现为 archive + projection；未来 radio/game 用同对象格式加成员，见设计稿 §17；
- 单文件 `.asar` 虚拟文件系统是可选上层打包，当前按对象 `.hdr/.dat` 更容易原子换钥/淘汰；
- 同 OS 用户仍可读进程内存；加密只保护静态磁盘与误浏览。

## 6. 手工验收

1. 两端安装 rc.15；底栏出现“托管保险柜”；
2. 本机 A 拉远端 B 会话 → A 的底栏显示 B 的根目录与容器数；
3. 再打开同一会话 → 无块传输、秒开；
4. A 底栏“删除内容” → 容器清零；再“更换目录”成功；
5. B 底栏“撤销托管” → A 下次打开回退完整拉取并删除旧容器；
6. 将 A 的默认目录设为不可写 → 拉取后出现倒计时 pending；不操作，倒计时结束自动拒绝；再输入可写目录，下一次拉取成功托管；
7. 把 `vault.keyTtl` 调短，等待票据过期后再次打开：不会自动删除旧密文；重新申请/完整拉取后替换。
